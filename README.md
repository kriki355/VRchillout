# VRchillout — VR-шоурум с редактором помещений

Веб-приложение для заказчика «Джимал Груп / Кибер 102»: редактор помещения в духе The Sims и прогулка по шоуруму на ПК и в Meta Quest 2 (WebXR). Один файл `site/index.html` — WebGL2 + WebXR без движков и сборки.

## Что умеет
- Редактор: размер зала, отсеки, этажи с лестничной клеткой и лифтом, двери/окна/ворота/проёмы, отделка пола, стен и потолка по комнатам, свет (круглые и квадратные светильники с тенями).
- Каталог мебели по группам, постановка кликом или перетаскиванием, поворот по 15°, варианты цвета, копия, отмена/повтор.
- Прогулка: WASD + мышь, карточки с характеристиками, двери и ящики открываются, предметы можно брать, на стулья садиться.
- VR (Quest 2): руки, лучи, телепорт и стик, круглая мини-карта на запястье, настройки, лифт между этажами.
- Спецификация и коммерческое предложение, синхронизация зала «Отправить в VR» (Netlify Function `site/netlify/functions/room.mjs`).

## Запуск
- Онлайн: залить папку `site` на Netlify (drag-and-drop).
- Локально: `python -m http.server 8765` в папке `site`, открыть http://localhost:8765 (не через file://).
- Quest: `start-vr-usb.bat` / `start-pc-airlink.bat`, сервер `server.ps1`.

## Папки
- `site/` — само приложение, текстуры `site/tex/`, иконки, манифест PWA.
- `tools/fbx/` — парсер FBX и упаковка мешей в JSON (int16/int8, base64), `tools/blend/` — разбор .blend.
- `tests/` — автотесты Playwright (swiftshader, WebXR-мок).
- `docs/` — схема и каталог моделей для защиты.
