VR-ШОУРУМ КАК ПРИЛОЖЕНИЕ В ШЛЕМЕ (APK через SideQuest)

Что получится: иконка «VR-шоурум» в библиотеке приложений Quest.
При запуске сразу открывается зал в VR, без окна браузера.
Внутри это тот же сайт, поэтому сайт должен лежать в интернете (Netlify).
Время: около 30–40 минут один раз. Потом обновлять APK не нужно — обновляешь только сайт.

ШАГ 1: ПОСТОЯННЫЙ САЙТ НА NETLIFY
1) зарегистрируйся на netlify.com (бесплатно);
2) открой app.netlify.com/drop и перетащи ПАПКУ site целиком (не zip и не index.html отдельно);
3) запиши адрес сайта, например: https://vr-showroom-123.netlify.app
4) проверь в браузере: https://ТВОЙ-АДРЕС/manifest.webmanifest — должен открыться текст.

ШАГ 2: ПОСТАВИТЬ NODE.JS
1) скачай Node.js LTS с nodejs.org и установи;
2) открой «Командную строку» и выполни:
   npm i -g @meta-quest/bubblewrap-cli
3) затем:
   bubblewrap doctor
   Он скачает Java (JDK) и Android SDK — соглашайся (y) на всё, включая лицензию.

ШАГ 3: СОБРАТЬ APK
1) создай пустую папку, например C:\vr-apk, и перейди в неё:
   mkdir C:\vr-apk
   cd C:\vr-apk
2) выполни (подставь свой адрес):
   bubblewrap init --manifest=https://ТВОЙ-АДРЕС/manifest.webmanifest --metaquest
   Мастер задаст вопросы. Почти везде жми Enter. Важное:
   - режим приложения (app mode / horizonOSAppMode) — выбери immersive;
   - пароль для ключа подписи — придумай и ЗАПИШИ, он нужен при каждой сборке.
3) собери:
   bubblewrap build
   Появится файл app-release-signed.apk

ШАГ 4: ПРИВЯЗАТЬ ПРИЛОЖЕНИЕ К САЙТУ (иначе не запустится)
1) в той же папке выполни:
   bubblewrap fingerprint generateAssetLinks
   Появится файл assetlinks.json
2) в папке site создай папку .well-known и положи туда assetlinks.json:
   site\.well-known\assetlinks.json
3) обнови сайт на Netlify: в панели сайта, вкладка Deploys, перетащи папку site ещё раз;
4) проверь: https://ТВОЙ-АДРЕС/.well-known/assetlinks.json должен открываться.

ШАГ 5: УСТАНОВИТЬ ЧЕРЕЗ SIDEQUEST
1) подключи шлем кабелем, открой SideQuest (вверху должна гореть зелёная точка);
2) перетащи app-release-signed.apk в окно SideQuest;
3) в шлеме: Библиотека приложений → фильтр «Неизвестные источники» → VR-шоурум.

ЕСЛИ ЧТО-ТО НЕ ТАК:
- приложение открывается с адресной строкой сверху — не подхватился assetlinks.json (шаг 4);
- приложение не запускается — проверь, что сайт открывается в браузере шлема;
- в VR не входит сам — нажми большую кнопку «Войти в VR» на экране;
- обновил шоурум — просто перетащи новую папку site на Netlify. APK пересобирать не надо.
